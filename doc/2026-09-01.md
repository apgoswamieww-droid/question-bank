# Question Entry module improvements (rich editor + compact wizard)

## Summary
Per user feedback: the Question Entry page was lengthy / hard to use, and it used a basic rich text editor while a full-featured Editor already exists. Two changes: (1) reuse the full Editor's capabilities in Question Entry's rich fields, and (2) redesign the layout into a compact tabbed wizard.

### Reusable rich editor
- `src/admin/components/RichEditor.tsx` (new) — reusable field editor that reuses the standalone Editor's extensions and tooling:
  - Extensions: `StarterKit`, `TextAlign`, `FontMark`, `ResizableImage`, `MathNode`.
  - Toolbar: font family (KAP fonts) + font size, bold/italic/underline/strikethrough, headings, alignment, bullet/numbered lists, image upload, math equation (`MathEditorModal`), Gujarati converter (`GujaratiConverterModal`), clear formatting, undo/redo.
  - Emits HTML on update and syncs from a `value` (HTML string or `{html}`) prop — same stored format as before.
- `QuestionEntryPage.tsx` — all three rich fields (Question Content, each MCQ option, Explanation) now use `RichEditor` instead of the old basic `QuestionRichText` (`QuestionRichText` is now unused but retained in the repo).

### Compact tabbed wizard layout
- Replaced the fixed 3-column grid (left hierarchy tree / center tall editor / right metadata) with a vertical wizard:
  - **Compact HierarchyBar** — Standard/Subject/Chapter/Topic as four linked selects (replaces the tall left tree; removed `LeftPanel`/`TreeLevel`).
  - **Question list** — moved into a collapsible "Browse" section (reuses `BottomStrip`), defaulting to hidden to reduce clutter.
  - **Wizard tabs** — `Question` (type + content + options/answer + solution), `Metadata` (reuses `MetadataPanel`), `Review` (compact preview + save).
  - Save (Draft / Publish) and History/Prev/Next actions are available in the toolbar row and per-tab.

### Verification
- `npm run lint` ✓, `typecheck` ✓, `test` (167) ✓, `build` ✓
- Removed now-unused `hierarchyStats` memo and `LeftPanel`/`TreeLevel` components; cleaned dead imports.

### Notes
- Question content/options are still persisted as `{ html }`, so existing stored content and the Test builder previews continue to work.
