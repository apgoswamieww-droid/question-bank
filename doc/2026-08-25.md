## Phase 3: KAP Verification Pipeline (Infrastructure)

### Design Limitation Found

`build-kap-mapping.mts` line 77 generated `String.fromCharCode(e.code)` — single-byte KAP output only. KAP encoding requires multi-byte sequences (e.g. `ગુજરાતી → VF5[,F` is 6 bytes).

### Changes Made

#### `scripts/enter-kap-mapping.mts` — Multi-byte sequence support
- Added `s <unicode> <kap-bytes>` input mode for sequence mappings
- Added `kapSequence` field to session entries (replaces implicit single-byte)
- Added `validateKapSequence()` for KAP output validation
- Updated help text with sequence examples

#### `scripts/build-kap-mapping.mts` — Multi-byte KAP output
- Now generates `{ unicode: <string>, kap: <multi-byte-sequence> }` rules
- Reports sequence mapping count in build output
- Test cases include `isSequence` flag and full KAP sequence

#### `src/converter/validation.ts` — Enhanced validation
- Added `warnings` field to `MappingValidation` return type
- Multi-byte KAP outputs generate warnings (informational, not errors)
- Improved error messages with rule content in output

#### `src/converter/kap112Golden.test.ts` — Independent golden sample test
- Tests the `ગુજરાતી → VF5[,F` sample independently from mapping table
- Validates sample definition, source documentation, checkSamples behavior
- Does NOT depend on any mapping rules being loaded

#### `src/converter/validation.test.ts` — Multi-byte KAP tests
- Added tests for multi-byte KAP outputs
- Added tests for conflicting multi-byte mappings
- Added tests for non-ASCII KAP output rejection

#### `doc/KAP112-VERIFICATION.md` — Verification workflow guide
- Priority order for human verification (vowels → consonants → matras → ...)
- Input grammar reference
- Targeted run examples
- Verification checklist

### Test Suite (77 tests, 5 files)
- New: `kap112Golden.test.ts` (8 tests)
- Enhanced: `validation.test.ts` (now 17 tests, +4)

### Safety Rules Enforced
- `verified: false` NOT changed for any font

## Exact Next Manual Action Required

1. Open `proof-sheets/KAP112/KAP112_full.pdf` in a PDF viewer
2. In a separate terminal, run:
   ```bash
   npx -y tsx scripts/enter-kap-mapping.mts KAP112
   ```
3. Start with Gujarati vowels (extended range bytes 161-170)
4. For each glyph, type the Gujarati character you see
5. Use `s <unicode> <kap-bytes>` for multi-byte sequence mappings
6. Use `q` to save and quit anytime
7. After completing entries, run:
   ```bash
   npx -y tsx scripts/build-kap-mapping.mts KAP112
   npm test
   ```
